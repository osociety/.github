## Projects

### [<img src="icons/mobile.svg" width="20" height="20" align="absmiddle"> Vernet](https://github.com/osociety/vernet)

[![release](https://img.shields.io/github/v/release/osociety/vernet?style=flat&label=release&color=5FDDD0)](https://github.com/osociety/vernet/releases/latest) [![downloads](https://img.shields.io/github/downloads/osociety/vernet/total?style=flat&label=downloads&color=1D7587)](https://github.com/osociety/vernet/releases) [![stars](https://img.shields.io/github/stars/osociety/vernet?style=flat&label=stars&color=1D7587)](https://github.com/osociety/vernet) [![license](https://img.shields.io/github/license/osociety/vernet?style=flat&label=license&color=1D7587)](https://github.com/osociety/vernet/blob/main/LICENSE)

Every device on your network — open ports, services, names in both directions, and connection speed, with history per device.

[![Google Play](https://img.shields.io/badge/-Google_Play-1D7587?logo=googleplay&logoColor=white&style=flat)](https://play.google.com/store/apps/details?id=org.fsociety.vernet.store) [![F-Droid](https://img.shields.io/badge/-F--Droid-1D7587?logo=f-droid&logoColor=white&style=flat)](https://f-droid.org/packages/org.fsociety.vernet) [![Snap](https://img.shields.io/badge/-Snap-1D7587?logo=snapcraft&logoColor=white&style=flat)](https://snapcraft.io/vernet) [![Microsoft Store](https://img.shields.io/badge/-Microsoft_Store-1D7587?style=flat)](https://apps.microsoft.com/detail/9N1170N3PHMM) [![macOS](https://img.shields.io/badge/-macOS-1D7587?logo=apple&logoColor=white&style=flat)](https://github.com/osociety/vernet/releases/latest) [![Linux](https://img.shields.io/badge/-Linux-1D7587?logo=linux&logoColor=white&style=flat)](https://github.com/osociety/vernet/releases/latest)

### [<img src="icons/terminal.svg" width="20" height="20" align="absmiddle"> Network Tools](https://github.com/osociety/network_tools)

[![pub](https://img.shields.io/pub/v/network_tools?style=flat&label=pub&color=5FDDD0&logo=dart&logoColor=white)](https://pub.dev/packages/network_tools) [![license](https://img.shields.io/github/license/osociety/network_tools?style=flat&label=license&color=1D7587)](https://github.com/osociety/network_tools/blob/main/LICENSE)

The engine underneath Vernet, usable on its own: host discovery, port scanning, mDNS, ping, and DNS in both directions.

[![Android](https://img.shields.io/badge/-Android-1D7587?logo=android&logoColor=white&style=flat)](https://github.com/osociety/network_tools) [![iOS](https://img.shields.io/badge/-iOS-1D7587?logo=ios&logoColor=white&style=flat)](https://github.com/osociety/network_tools) [![macOS](https://img.shields.io/badge/-macOS-1D7587?logo=apple&logoColor=white&style=flat)](https://github.com/osociety/network_tools) [![Linux](https://img.shields.io/badge/-Linux-1D7587?logo=linux&logoColor=white&style=flat)](https://github.com/osociety/network_tools) [![Windows](https://img.shields.io/badge/-Windows-1D7587?style=flat)](https://github.com/osociety/network_tools) [![Web](https://img.shields.io/badge/-Web-1D7587?logo=googlechrome&logoColor=white&style=flat)](https://github.com/osociety/network_tools)

### [<img src="icons/package.svg" width="20" height="20" align="absmiddle"> Network Tools Flutter](https://github.com/osociety/network_tools_flutter)

[![pub](https://img.shields.io/pub/v/network_tools_flutter?style=flat&label=pub&color=5FDDD0&logo=flutter&logoColor=white)](https://pub.dev/packages/network_tools_flutter) [![license](https://img.shields.io/github/license/osociety/network_tools_flutter?style=flat&label=license&color=1D7587)](https://github.com/osociety/network_tools_flutter/blob/main/LICENSE)

The Flutter layer, where it absorbs what pure Dart cannot: mDNS permissions, background scans, per-platform stack differences.
